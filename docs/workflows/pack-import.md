# 词包导入工作流

这个流程用于把新的教材词表、安全地接进当前项目。

## 目标

- 保证字段结构统一
- 保证词条能被当前页面直接消费
- 避免导入后才发现缺列、缺句子、主题混乱

## 推荐步骤

1. 先用家长端下载模板。
2. 按模板准备字段：
   - `word`
   - `meaningZh`
   - `topic`
   - `unit`
   - `example`
   - `exampleZh`
   - `image`
   - `audio`
3. 优先补 `example` 和 `exampleZh`，这样新词卡和题型页都会有句子。
4. 如果没有图片，允许留空；系统会走内置图形兜底。
5. 导入后先检查：
   - 当前词库名称是否切换成功
   - 地图主题是否可见
   - 今日任务能否正常生成
   - 进度页总词数是否匹配

## 导入后回归检查

- 选一个新主题进入今日任务
- 确认新词卡能看到英文、中文、句子
- 确认题型页能显示图形
- 确认进度页总词量变化正确

## 什么时候需要回到代码层处理

出现下面情况时，再进代码层：

- 主题命名混乱，需要统一映射
- 同一词重复过多，需要去重策略
- 默认图形覆盖不足，需要补 `wordVisualMap`
- 教材字段和模板差异太大，需要扩展 `normalizeImportedPack`
