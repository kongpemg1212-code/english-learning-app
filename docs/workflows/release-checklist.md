# 发布检查清单

这个清单用于每次发布到 GitHub Pages 前的最小验证。

## 代码验证

依次执行：

```bash
npm run test
npm run lint
npm run build
```

## 产品验证

至少手动检查这 6 项：

1. 首页能进入今日任务。
2. `开始今天的冒险` 按钮能进入学习流。
3. 新词卡能正常显示单词、中文、句子。
4. 地图主题能切换。
5. 花园规则和奖励展示正常。
6. 进度页能看到最近学习记录。

## 内容验证

- 默认 Cambridge 词库能正常加载
- 新导入词库能切换
- 高优先级主题的图形兜底正常

## 发布后检查

发布成功后检查：

- GitHub Pages 地址是否打开正常
- 首屏是否仍然是旧缓存页面
- `dist/standalone.html` 是否可本地打开

## 风险提醒

- 任何涉及本机 SQLite、账号切换、恢复方式的变更，都必须额外做一次真实环境验证
- 任何词库结构调整，都必须额外检查地图主题和今日任务生成
