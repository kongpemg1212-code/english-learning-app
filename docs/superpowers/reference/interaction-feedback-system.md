# 微反馈与音效系统

> 目标：把“孩子为什么愿意继续点下一题”拆成可实现的反馈组件，而不是留到最后做表面润色。

## 1. 设计原则

- 即时反馈优先于长说明
- 答对强化成就感
- 答错提供安全感
- 连击制造节奏感
- 完成任务给完整庆祝闭环

## 2. 答对反馈

至少同时触发三类反馈中的两类：

- 视觉：粒子、光晕、按钮弹跳、飘字
- 音频：轻快短音效
- 触觉：移动端轻震动

推荐随机文案：

- 太棒了！
- 你真厉害！
- 太快啦！
- 答对啦！
- 真聪明！

## 3. 连击反馈

当连续答对达到阈值时触发：

- `2 连击`：轻提示
- `3 连击`：显示 combo
- `5 连击`：更强音效或更明显特效

原则：

- 强化节奏感
- 不压迫孩子
- 不因断连击而惩罚

## 4. 答错反馈

答错时禁止使用强惩罚表达，例如大红叉、失败音爆、扣星。

推荐方式：

- 轻微摇晃
- 正确答案高亮
- 温和文案
- 给下一次尝试留希望

推荐文案：

- 没关系，再试一次
- 快接近啦
- 这次记住了
- 下次一定行

## 5. 完成任务反馈

今日任务完成时，建议组合：

- 全屏纸屑或烟花
- 胜利音效
- 花园立即生长一截
- 地图节点变亮
- 出现“明天再来”的温暖提醒

## 6. 音效清单

首版建议至少有：

- `tap`
- `correct`
- `wrong-soft`
- `combo`
- `mission-complete`
- `garden-grow`

要求：

- 所有音效长度短
- 不刺耳
- 音量统一
- 支持一键关闭

## 7. 触觉反馈

移动端支持时：

- 答对：轻短震
- 连击：节奏感更明显的轻震
- 答错：尽量不用或只做极轻震

桌面端可忽略。

## 8. 组件建议

建议实现时拆成：

- `AnswerFeedback`
- `ComboMeter`
- `FloatingScore`
- `CelebrationBurst`
- `MissionCompleteOverlay`
- `useSound`

## 9. 与学习机制的边界

微反馈系统负责：

- 情绪强化
- 完成感
- 节奏感

不负责：

- 决定对错
- 决定是否掌握
- 决定复习时间

这些由学习引擎和 session builder 负责。
