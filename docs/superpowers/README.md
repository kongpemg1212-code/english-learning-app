# 少儿单词背诵文档索引

本目录保存“少儿英语单词闯关 PWA”项目的设计与实施文档。

## 文档清单

- [项目总控文档](../project-control.md)
  汇总当前代码能力、词库状态、历史记录模式、导入能力和后续约束，是当前项目的最高层入口。

- [设计规格](./specs/2026-04-12-kids-vocabulary-pwa-design.md)
  定义产品目标、用户场景、玩法、记忆机制、页面结构、技术路线、风险与成功指标。

- [实现计划](./plans/2026-04-12-kids-vocabulary-pwa.md)
  将设计规格拆成可以直接执行的工程任务，包含建议文件结构、测试策略与阶段性验收标准。

- [词包数据协议](./reference/word-pack-schema.md)
  约定词包目录结构、字段定义、命名规则、媒体资源与示例 JSON。

- [复习调度规则](./reference/review-scheduler.md)
  定义首版 Leitner 调度、错题回流、每日任务生成和后续升级到 FSRS 的边界。

- [教材导入协议](./reference/textbook-import-contract.md)
  约定 CSV/Excel/JSON 导入字段、清洗规则、去重逻辑、输出格式与错误处理。

- [视觉设计系统](./reference/visual-design-system.md)
  约定色彩 token、字体、圆角、背景、插画风格、地图和花园视觉方向，以及减少动画模式。

- [微反馈与音效系统](./reference/interaction-feedback-system.md)
  约定答对、答错、连击、完成任务时的动效、文案、音效和触觉反馈原则。

## 使用顺序

1. 先看设计规格，确认产品边界和第一版目标。
2. 再看实现计划，决定开发顺序和测试方法。
3. 进入开发前，按需参考以下依赖文档：
   - 内容与词库工作看“词包数据协议”
   - 复习算法实现看“复习调度规则”
   - 后续接教材或自定义词表看“教材导入协议”
   - 视觉和动效实现看“视觉设计系统”
   - 奖励与音效实现看“微反馈与音效系统”

## 当前结论

- 端形态：网页 / PWA
- 当前默认内容源：Cambridge YLE Pre A1 Starters 主题词包
- 使用对象：孩子端优先，家长端轻量查看
- 产品形态：闯关地图 + 成长花园 + 每日短时复习
- 记忆机制：首版 Leitner，后续可迁移到 FSRS
- 体验策略：第一秒可互动、题型有变化、反馈有情绪、奖励可见可感
- 家长入口：已支持 CSV 模板下载、词表导入、词库切换
- 历史记录：当前为浏览器本地持久化，无需密码
